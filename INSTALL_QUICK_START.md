## 5-Minute Installation Overview

```
┌─────────────────────────────────────────────────────────────────┐
│  Step 1: DOWNLOAD                                               │
│  ├─ Go to: https://github.com/AmeerHussain-ops/KanoonVault     │
│  ├─ Click: Releases                                             │
│  ├─ Download: KanoonVault-Setup.exe (~500-700 MB)              │
│  └─ Wait: File downloads to Downloads folder                   │
└─────────────────────────────────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 2: RUN INSTALLER                                          │
│  ├─ Double-click: KanoonVault-Setup.exe                        │
│  ├─ Click: Yes (if Windows asks for permission)                │
│  └─ Wait: Installer wizard opens                               │
└─────────────────────────────────────────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 3: FOLLOW WIZARD                                          │
│  ├─ License → Click "I Agree"                                  │
│  ├─ Location → Keep default or change (click Next)             │
│  ├─ Options → Keep checkboxes selected (click Next)            │
│  ├─ Ready → Click "Install"                                    │
│  └─ Wait: 2-3 minutes (unpacking files)                        │

                              ▼

│  Step 4: FIRST-LAUNCH SETUP                                     │
│  ├─ Welcome Screen → Click "Get Started"                       │

│  ├─ API Key → Paste OpenRouter key (or skip)                   │
│  │           → Click "Test Connection"                         │
│  │           → If green ✓ → Click "Continue"                   │
│  └─ Dashboard loads → Ready to use!                            │

```

## After Installation: Where Are My Files?

```
Your Computer
│
├─ C:\Program Files\KanoonVault\        ← Application (read-only)
│  ├─ launcher.exe                      ← Click to start app
│  ├─ python/                           ← Bundled Python
│  ├─ fastapi/                          ← Web server
│  └─ frontend/                         ← User interface
│
├─ C:\Users\<YourName>\
│  └─ AppData\
│     ├─ Local\KanoonVault\             ← ⭐ YOUR DATA (persistent)
│     │  ├─ databases/                  ← Cases and metadata
│     │  ├─ documents/                  ← Uploaded files
│     │  ├─ uploads/                    ← Processing temp files
│     │  └─ vector_db/                  ← Search index
│     │
│     └─ Roaming\.kanoonvault\          ← Configuration
│        └─ storage-config.json         ← Setup status
│
└─ (Optional) OpenRouter API            ← External (AI only)
   http://api.openrouter.ai/            ← No data stored here

Key Point: Your legal documents NEVER leave C:\Users\<YourName>\AppData\Local\KanoonVault\
```

## Common Installation Issues

### Problem: "Windows protected your PC"
```
┌──────────────────────────────────────┐
│  Windows Defender SmartScreen        │
│  Windows protected your PC           │
│                                      │
│  Windows Defender Smartscreen        │
│  prevented an unrecognized app from  │
│  starting. Running this app might    │
│  put your PC at risk.                │
│                                      │
│  ✓ ☐ Get more info about this app   │
│  □ Don't show this again             │
│                                      │
│           [ Run anyway ] [ Cancel ]  │
└──────────────────────────────────────┘
```
**Solution:** Click "Run anyway" - This is normal for new apps

### Problem: "Not enough space"
```
Installation error: 
Requires 750 MB, only 500 MB available
```
**Solution:** Free up disk space or install to different drive

### Problem: "Permission denied"
```
Installation error:
Access denied - insufficient permissions
```
**Solution:** Right-click installer, select "Run as administrator"

## First Launch Scenarios

### Scenario A: Everything Works ✅
```
Download → Install → Setup → Dashboard loads → Done! 🎉
```

### Scenario B: Need API Key Later
```
Download → Install → Setup (skip API key) → Dashboard loads
Later: Settings → Add API Key → Restart → AI features work
```

### Scenario C: Need to Change Storage Location
```
Download → Install → Setup → Storage location changed
Old files backed up → New location initialized → All data migrated
```

### Scenario D: Uninstall & Reinstall
```
Uninstall (Program Files removed, AppData preserved) 
         ↓
Reinstall
         ↓
Setup skipped (first_run complete, configuration loaded)
         ↓
Dashboard with all data preserved ✓
```
